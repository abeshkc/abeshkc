Modify Aria so that it supports full voice-driven and text-driven editing workflows for notes and reminders.

Goal:
Aria should evolve from a simple creator/search assistant into an interactive organizer that can:
- search notes/reminders
- open them
- edit them
- append text
- update fields
- save changes
- close items

through both voice commands and typed commands.

Aria should remain accessible throughout the app, not only on the main dashboard.

1. Add voice/text editing workflow support

Implement conversational editing capabilities for:
- notes
- meeting notes
- reminders

Aria should support commands such as:

Search:
- “Aria, find my notes about Stanford engineering.”
- “Search reminders related to Yemen.”
- “Find urgent reminders.”

Open:
- “Aria, open the note titled Stanford engineering.”
- “Open the reminder about the DIEM report.”

Edit/add content:
- “Aria, add the following to the note: LLMs are fun.”
- “Append this text to the reminder details.”
- “Change the reminder time to 5 PM.”
- “Mark this reminder as urgent.”
- “Update the title to Stanford AI Notes.”

Save/close:
- “Aria, save and close.”
- “Save changes.”
- “Close this note.”

2. Aria must be globally accessible

Currently Aria appears mainly in the main window.

Modify the app so Aria is accessible from:
- notes window
- reminder window
- meeting notes editor
- search panel
- edit dialogs

The user should always be able to:
- click Aria
- speak commands
- type commands

without returning to the home screen.

3. Add conversational editing context

Aria should maintain lightweight editing context.

Example workflow:
- User searches notes
- User opens a specific note
- User says:
  “Add this to the note...”
- Aria should know which note is currently active

Aria should track:
- currently opened note/reminder
- active editing target
- last search results
- selected item

so follow-up commands work naturally.

4. Add active document context awareness

If a note/reminder is already open in edit mode:
- Aria should assume edit commands apply to the active item unless clarified.

Examples:
- “Add this paragraph.”
- “Change the title.”
- “Set importance to urgent.”
- “Save.”
- “Close.”

5. Add edit intent parsing

Update Claude parser schema to support editing commands.

Add intents such as:
- search_note
- search_reminder
- open_note
- open_reminder
- update_note
- update_reminder
- append_note
- append_reminder
- save_active_item
- close_active_item

Example schema:

{
  "intent": "update_note",
  "confidence": 0.92,
  "requires_confirmation": false,
  "target": {
    "type": "note",
    "id": 15,
    "title": "Stanford Engineering"
  },
  "fields_to_update": {
    "details_append": "LLMs are fun"
  },
  "action_summary": "Append text to active note"
}

6. Add append vs replace behavior

Aria must distinguish between:
- append
- replace
- overwrite

Examples:
- “Add this to the note” → append
- “Replace the note content with...” → overwrite
- “Change the title to...” → replace title field

Destructive overwrites should require confirmation.

7. Add voice editing mode feedback

While editing:
- show active note/reminder title
- show “Editing: Stanford Engineering”
- highlight active editing target visually

When Aria updates content:
- show a diff or preview if possible
- or show:
  “Added text to note.”

8. Save workflow

If user says:
- “save”
- “save changes”
- “save and close”

Aria should:
- save the active item
- optionally close it
- update modified timestamp

If there are no changes:
- show:
  “Nothing to save.”

9. Close workflow

If user says:
- “close”
- “close this note”
- “exit editing”

Aria should:
- close the active editing view
- warn if unsaved changes exist

10. Search integration

Search results should integrate smoothly with editing.

Workflow example:
- User searches
- Aria returns matching results
- User selects/open result
- Editing begins immediately

Search results should remain clickable.

11. Typed assistant commands

The same commands should work via:
- voice
- typed assistant input

Examples:
- typing:
  “open my note on Stanford engineering”
- typing:
  “append LLMs are fun”

should work identically.

12. UI improvements

Add:
- active editing banner
- editable status indicators
- save state indicators
- subtle animation when Aria updates a note/reminder

Keep UI clean and lightweight.
