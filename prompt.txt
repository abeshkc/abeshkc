Modify the app so that Aria feels alive, emotionally engaging, and more like a real personal organizer companion instead of just a utility tool.

Goal:
When the app loads, Aria should greet the user, visually appear as a friendly AI companion, and proactively engage with the user based on reminders, meetings, notes, unfinished tasks, and stored information.

The experience should feel:
- warm
- intelligent
- helpful
- lightly conversational
- motivating
- personal but not creepy
- productivity-focused

1. Add animated Aria character/avatar

When the app launches, display a cartoon-style robot/AI face representing Aria.

Requirements:
- modern and friendly design
- not childish
- expressive but lightweight
- should fit the premium productivity aesthetic
- should work in dark and light mode

Behavior:
- idle blinking or subtle movement
- gentle pulse/glow while speaking/thinking
- listening animation when voice mode is active
- expression changes slightly depending on context:
  - happy
  - neutral
  - thinking
  - reminder/warning

Be creative.

Possible inspirations:
- futuristic assistant
- minimal robot face
- holographic AI orb with eyes
- floating AI avatar
- subtle animated assistant portrait

Do NOT make it look like a gaming mascot or cartoon toy.

2. Add startup greeting experience

When the app opens, Aria should greet the user dynamically.

Examples:
- “Welcome back.”
- “You have 4 reminders coming up this week.”
- “You had 3 meetings yesterday. Hope they went well.”
- “You marked 5 tasks as done this week. Nice progress.”
- “One of your notes mentioned buying a watch. Did you get it?”
- “You have an important reminder tomorrow morning.”
- “You haven’t reviewed your Yemen notes in a while.”

The greeting should:
- be generated dynamically from stored app data
- feel natural and conversational
- vary from day to day
- avoid repetitive robotic phrasing

3. Context-aware engagement system

Create a lightweight “Aria engagement engine”.

Aria should be able to:
- summarize upcoming reminders
- mention overdue tasks
- reference unfinished items
- mention recent meetings
- recall relevant notes
- encourage productivity
- gently follow up on personal notes/tasks

Examples:
- “You still have 2 urgent reminders not completed.”
- “There’s a recurring meeting tomorrow afternoon.”
- “You created a note about improving your report workflow.”
- “You haven’t opened your Lebanon meeting notes recently.”

Important:
- keep interactions concise
- no long paragraphs
- avoid sounding intrusive or creepy
- avoid over-personalization

4. Add “Daily Briefing” panel

Add a small “Daily Briefing” or “Aria Update” section near the assistant avatar.

This section can contain:
- today’s reminders
- overdue items
- meeting count
- upcoming deadlines
- motivational/contextual messages
- recent activity summary

Example:
--------------------------------
Good morning.

• 3 reminders today
• 1 overdue task
• 2 meetings this afternoon
• Last note edited: Yemen Brief
--------------------------------

5. Voice and animation integration

When Aria is:
- listening → avatar animates
- processing → thinking animation
- responding → subtle glow/movement
- idle → calm breathing/blinking animation

Keep animations lightweight and responsive.

6. Add intelligent conversational prompts

Aria should occasionally ask lightweight contextual questions.

Examples:
- “Did you finish the report you mentioned yesterday?”
- “Do you want me to create a reminder for that?”
- “You seem to have several overdue tasks this week.”
- “Would you like to review your meeting notes?”

Important:
- these should be occasional
- not spammy
- configurable in settings
- user can disable proactive suggestions

7. Add settings for personality behavior

Add settings such as:
- Enable Aria greetings
- Enable proactive suggestions
- Greeting frequency
- Animation intensity
- Quiet mode
- Minimal mode

8. Data awareness

Aria can use:
- reminders
- overdue reminders
- notes
- meeting notes
- Microsoft calendar imports
- recurring reminders
- Done history
- importance/priority

to generate contextual messages.

Do NOT:
- expose sensitive data unnecessarily
- send these summaries to external APIs unless already part of the existing Claude workflow
- sound invasive

9. Optional lightweight memory layer

If feasible, add lightweight contextual tracking such as:
- recently mentioned goals
- frequently referenced topics
- unfinished recurring themes

Examples:
- “You’ve mentioned AI research several times this week.”
- “You still have unfinished reminders related to reports.”

Keep this simple and local.

10. UI integration

The Aria avatar + greeting should appear:
- on startup/dashboard/home screen
- near the voice interaction area
- in a visually prominent but non-intrusive way

The UI should feel:
- modern
- assistant-driven
- alive
- clean

11. Preserve existing functionality

Do not remove or break:
- local Whisper transcription
- Claude API parsing
- reminders
- recurring reminders
- notes
- meeting notes
- Microsoft sync
- sorting
- adjustable layouts
- reminder popups
- voice-first workflow

12. Tests

Add/update tests for:
- Aria avatar loads successfully
- greeting panel appears on startup
- reminder summaries generate correctly
- overdue reminders appear in briefing
- meetings summary works
- proactive prompts can be enabled/disabled
- animations trigger during listening/processing
- contextual messages do not crash when data is missing

Update README with:
